# Profile icons

Static SVG logos extracted from the Shields.io / Custom Icon Badges images previously used in this profile:

- C# (`cs2`) and Java (`java`): https://github.com/DenverCoder1/custom-icon-badges
- Unity, Blender and Steam: https://github.com/simple-icons/simple-icons via https://shields.io
- Go, Python, Spring and React: https://github.com/simple-icons/simple-icons (downloaded from `icons/` on 2026-09-07).
- Electron and JavaScript: https://github.com/simple-icons/simple-icons (downloaded from `icons/` on 2026-09-08).
- NeoForge: user-supplied `256.png`, traced into `neoforge.svg` with its gray background omitted (2026-09-09).
- UdonSharp: left-hand symbol from user-supplied `5fe69880-f94c-11ea-91d5-cd60400060c2.png`, traced from its alpha silhouette into `udonsharp.svg`. Project badges apply the same solid SVG fill as the other icons, without raster color filters (2026-09-09).

Brand names and logos identify the corresponding tools and services. Card generation reads these local files; it makes no network requests.

The `../project-tech-*-dark.svg` and `../project-tech-*-light.svg` assets embed these logos with readable text labels for the project tables. Their colors match the profile cards.
