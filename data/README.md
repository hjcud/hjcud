# 소개 카드와 작업 공간 이미지

## 프로젝트 타임라인

`project-timeline.json`에서 상단 타임라인을 관리합니다. `name`은 이름, `start`는 정렬용 시작 연월(`YYYY-MM`), `period`는 표시할 기간, `role`은 담당 역할입니다. 확인한 활동기간만 입력하며 저장소 생성일을 프로젝트 시작일로 대신하지 않습니다. 시작 연월이 최근인 프로젝트부터 표시됩니다. 전체 프로젝트는 아래 접힌 목록에서 관리하고, 타임라인에는 기간을 확인한 주요 프로젝트를 선택해 넣습니다.

이 파일을 수정해 push하면 GitHub Actions가 라이트·다크 카드를 갱신합니다. 로컬에서는 `node scripts/render-project-timeline.cjs`를 실행합니다.

Pixel Mat의 2026년 9월과 Miniworld의 2026년 10월은 사용자가 지정한 기준인 관련 작업 대화의 시작 시점으로 정리했습니다. 바로 영업은 사용자가 알려준 8월 시작을 연월 단위로 표시했습니다. 타임라인과 프로젝트 표의 역할은 짧은 담당 영역으로 유지합니다.

## 소개 카드

소개 카드의 문구와 디자인은 `scripts/render-profile-cards.cjs`에서 관리합니다. `assets/mypc.png`를 교체해서 push하면 소개 카드도 자동으로 다시 생성됩니다. 원본 PNG는 그대로 보관하며, SVG 카드에 포함해 표시합니다. 로컬 생성 명령은 `node scripts/render-profile-cards.cjs`입니다.

작업 공간의 스캔 효과에는 `assets/mypc_wire.png`를 사용합니다. 렌더 이미지와 같은 구도·크기로 교체하면 됩니다. 9초 주기로 약 4초간 와이어프레임 띠가 지나가고 나머지 시간에는 원본을 보여줍니다. 동작 줄이기 설정에서는 정지 이미지를 표시합니다. 원본 PNG는 변경하지 않고 SVG 필터와 마스크로 선의 색과 표시 영역을 조정합니다.

## 프로젝트 목록 수정하기

[프로필 README](../README.md)의 `Projects` 아래에서 해당 상태의 `<details>` 안에 표 행을 추가하세요. `In Progress`는 진행 중, `On Hold`는 보류, `Completed`는 종료, `Planned`는 계획 중인 프로젝트입니다. 각 목록은 처음에는 접혀 있으며 제목을 클릭하면 펼쳐집니다. 제목 옆 숫자는 프로젝트 개수이므로 행을 추가하거나 옮길 때 함께 수정하세요.

```markdown
| [프로젝트 이름](https://github.com/사용자/저장소) | 한 줄 설명 | 사용 기술 |
```

아직 저장소가 없는 계획은 프로젝트 이름을 링크 없이 적어도 됩니다. 비공개 저장소는 이름 아래 `<br><sub>Private</sub>`로 표시합니다. 기술 배지는 기존 행의 `<picture>...</picture>`를 복사해 재사용할 수 있으며, 아이콘이 없는 기술은 텍스트로 적어도 됩니다. `<summary>` 다음과 `</details>` 앞의 빈 줄은 유지하세요. 상태가 바뀌면 해당 행을 다른 목록으로 옮기면 됩니다. 카드 생성 작업은 이 목록을 유지합니다.
